# Проверка проекта

Проверено 3 октября 2026 года после перевода интеграции на Telegram.

| Проверка               | Результат                                                                                      |
| ---------------------- | ---------------------------------------------------------------------------------------------- |
| `npm test`             | 20 тестов, 2 файла, все проходят                                                               |
| `npm run build`        | TypeScript и production-сборка Vite проходят                                                   |
| `npm audit --omit=dev` | 0 известных уязвимостей в runtime-зависимостях                                                 |
| Браузер, 1280 × 720    | Подключение, инструкция, демочат, отправка по Enter и ответ, поиск, создание чата с номером +1 |
| Браузер, 390 × 844     | Мобильная переписка и возврат к списку чатов                                                   |
| Браузер, 320 × 568     | Форма подключения прокручивается; ширина документа 320 px, горизонтального переполнения нет    |

Production-предпросмотр проверен в браузере. Ошибок и предупреждений в консоли не обнаружено. Скриншоты обновлены: экран подключения, настольная и мобильная переписка. Они показывают деморежим с локальными вымышленными данными.

Автоматические проверки используют тестовый HTTP-транспорт GREEN-API: авторизация, настройки, CheckAccount, SendMessage, ReceiveNotification и DeleteNotification. Проверены международные номера, сохранение явного кода +81, ограничения поиска Telegram в ответе HTTP 200, внутренний chatId, дедупликация, сохранение до подтверждения уведомления, ошибки отправки и повтор по явной команде, сохранение черновика, независимость отправки от перезапуска получения.

Полный пользовательский сценарий также проверяет, что история сохраняется под ключом Telegram, старый ключ MAX не изменяется, а токен не попадает в localStorage. Ошибки доставки без idMessage подтверждаются и показываются общим предупреждением, без присвоения ошибочного статуса одному из нескольких сообщений.

Контракт сверён с официальной [документацией GREEN-API для Telegram](https://green-api.com/telegram/docs/). Формат URL остаётся `/waInstance<id>/<method>/<token>`; имя waInstance используется сервисом и для Telegram.

**Реальная переписка Telegram ещё не проверена.** Для неё нужен авторизованный личный инстанс и получатель. Проверить отправку, ответ с телефона, CORS конкретного хоста и ограничения тарифа нужно по разделу README «Проверка реальной переписки». Деморежим и тестовый транспорт не подтверждают работоспособность конкретного инстанса.
