# Проверка проекта

Проверено 2 октября 2026 года.

| Проверка               | Результат                                                 |
| ---------------------- | --------------------------------------------------------- |
| `npm test`             | 17 тестов, 2 файла, все проходят                          |
| `npm run build`        | TypeScript и production-сборка Vite проходят              |
| `npm audit --omit=dev` | 0 известных уязвимостей в runtime-зависимостях            |
| Браузер, 1280 × 720    | Экран входа, демочат, отправка и ответ, поиск, новый чат  |
| Браузер, 390 × 844     | Мобильная переписка, возврат к чатам, многострочный текст |

Автоматические проверки полного сценария используют тестовый HTTP-транспорт: подключение, CheckAccount, SendMessage, ReceiveNotification и DeleteNotification. Покрыты ошибки запроса, повтор отправки по явной команде, дедупликация, ошибка локального сохранения, статус noAccount и независимость отправки от перезапуска получения.

**Реальный инстанс GREEN-API не был предоставлен.** Отправка в настоящий MAX, ответ с телефона, CORS конкретного хоста и ограничения тарифа ещё требуют ручной проверки по README. Скриншоты демонстрируют интерфейс с локальными данными, а не факт подключения к MAX.
