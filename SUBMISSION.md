# Подготовка к отправке тестового задания

Перед сдачей:

- Создать и авторизовать инстанс GREEN-API WhatsApp по README.
- Проверить реальную отправку и ответ со второго аккаунта WhatsApp.
- Загрузить исходники и package-lock.json в свой GitHub-репозиторий. node_modules и dist включать в репозиторий не нужно.
- Скопировать ссылку на репозиторий и на README с инструкцией локального запуска.
- По желанию разместить dist на HTTPS-хостинге и записать короткое видео реальной переписки. Не показывать токен в кадре.
- Приложить своё резюме PDF и указать Telegram для связи.
- Выбрать формат работы: удалённо, офис Химки или офис Астана.

Документ задания указывает адрес **hr@green-api.com**. Письмо не отправлено автоматически. Ниже — черновик, в котором нужно заменить поля в квадратных скобках своими данными.
